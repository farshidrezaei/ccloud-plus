# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in CCloud+, please do not disclose it publicly in an open issue.

Instead, please send an email to **farshid.net1@gmail.com** with:
- A description of the vulnerability.
- Steps or a proof-of-concept demonstrating the issue.
- Impact assessment.

We take all security reports seriously and will acknowledge receipt within 48 hours and work with you to patch the issue promptly.
